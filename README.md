# הטיול המשפחתי 2026

אתר משפחתי בעברית לטיול ביער השחור ובשווייץ, 19–29 בספטמבר 2026.

האתר כולל דף מסלול והזמנות, לצד דף נפרד של רעיונות לימים מלאים עם קישורים רשמיים לאטרקציות.

## עדכון פרטי הטיול

כל תוכן המסלול, הטיסות, מקומות הלינה ורשימת הציוד נמצא בתחילת הקובץ `app.js` בתוך `tripData`.

חשוב: אין להוסיף לאתר מספרי דרכון, פרטי תשלום, קודי הזמנה או מידע אישי רגיש. אתר GitHub Pages עשוי להיות גלוי לציבור גם כאשר מאגר הקוד פרטי.

## הלו״ז המשותף

הגרסה הסטטית של האתר נשמרה בתג Git בשם `stateless-state`.

הלו״ז הפעיל נשמר ב-Cloud Firestore ומוצג לציבור בזמן אמת. הכניסה לעריכה נעשית באמצעות Google. רשימת העורכים הקבועה מוגדרת בשני מקומות שחייבים להישאר מסונכרנים:

- `firebase-client.js` — תצוגת הרשאות בממשק.
- `firestore.rules` — אכיפת הרשאות בצד השרת.

כל תאריך נשמר כמסמך יחיד באוסף `schedule`, ולכן אפשר לשבץ לכל יום פעילות אחת בלבד. ניתן לערוך רק את הימים המלאים 20–24 ו-26–28 בספטמבר.

פרטי החיבור הציבוריים ב-`firebase-client.js` אינם סוד. הרשאות הכתיבה נאכפות באמצעות Firebase Authentication וכללי Firestore.

לפרסום שינוי בכללי האבטחה:

```powershell
firebase deploy --only firestore:rules
```

## הרצה מקומית

אפשר לפתוח את `index.html` ישירות בדפדפן. יכולות אופליין מלאות מופעלות רק כאשר האתר מוגש ב-HTTPS.

## פרסום

האתר מיועד לפרסום באמצעות GitHub Pages מתוך ענף `main`.
